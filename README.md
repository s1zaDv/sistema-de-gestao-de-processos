# Fluxo — Gestão de Processos

Sistema web desenvolvido para facilitar o gerenciamento e o acompanhamento de processos internos de empresas, centralizando informações e oferecendo uma visão organizada das atividades.

## Sobre o projeto

O Fluxo é uma aplicação de gestão de processos que busca substituir controles manuais e planilhas desorganizadas por uma interface simples e intuitiva.

A proposta é permitir que equipes acompanhem solicitações, responsáveis, prazos e status em um único ambiente.

## Funcionalidades

- **Cadastro de processos:** registro de novas solicitações com informações detalhadas.
- **Edição de registros:** atualização das informações dos processos cadastrados.
- **Exclusão de processos:** remoção de registros.
- **Controle de status:** acompanhamento de processos pendentes, em andamento, concluídos ou cancelados.
- **Controle de prazos:** identificação de processos atrasados.
- **Pesquisa:** busca por nome do processo, responsável ou setor.
- **Filtros:** visualização de processos conforme seu status.
- **Painel de indicadores:** resumo de processos totais, em andamento, concluídos e atrasados.
- **Armazenamento local:** persistência dos dados utilizando LocalStorage.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

O projeto foi desenvolvido sem frameworks ou bibliotecas externas.

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` em seu navegador.
4. Comece a cadastrar e gerenciar processos.

Não é necessário instalar dependências ou configurar um servidor para utilizar a demonstração.

## Armazenamento

Os dados são armazenados localmente no navegador por meio do LocalStorage.

Isso permite manter os registros mesmo após fechar e abrir a página novamente no mesmo navegador.

**Importante:** esta versão é um protótipo funcional. Os dados não são compartilhados entre usuários ou dispositivos e ainda não existe integração com banco de dados ou autenticação.

## Objetivo

Este projeto tem como objetivo explorar o desenvolvimento de aplicações web voltadas à gestão empresarial, aplicando conceitos de lógica de programação, manipulação do DOM, funções, estruturas condicionais e organização de dados.
